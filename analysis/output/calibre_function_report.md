# Artillery calibre — can a smooth f(range, damage) replace the cannon-type one-hot?

Generated by `analysis/calibre_function.py` (500 split seeds, 12 min). Merged artillery slice, with the same folds and nested coarse power descent as `unit_pricing.py`. Everything except the calibre representation is the adopted artillery model: guns^1.2 × rating + c, with additive crew stats and fitted powers.

## 1. Does calibre alone fix range and damage?

**Yes.** Each of the 17 projectiles has exactly one range, damage, gun reload and shot type, and canister is one per calibre too. So any f(range, damage) is a function of calibre, and the cannon-type one-hot is the most flexible such function.
